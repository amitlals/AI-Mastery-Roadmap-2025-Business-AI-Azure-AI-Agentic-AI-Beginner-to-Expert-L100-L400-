# Contributing to the AI Mastery Roadmap

Thanks for considering a contribution! This roadmap stays useful only if it stays current — and the AI field moves in weeks, not years.

## Ways to help

| Contribution | How |
|---|---|
| 🐛 **Report dead links** | [Open an Issue](https://github.com/amitlals/AI-Mastery-Roadmap-2025-Business-AI-Azure-AI-Agentic-AI-Beginner-to-Expert-L100-L400-/issues/new) with the section + URL |
| 📝 **Fix typos / phrasing** | Direct PR — go for it |
| 🆕 **Add a course / resource** | PR to the relevant level (L100–L400). Include: name, provider, duration, cost, link, why it's high-signal |
| 🎓 **Update cert info** | PR to `docs/certifications/<cloud>.md` and the main README cert table |
| 🛤️ **Improve a track guide** | PR to `docs/tracks/<track>.md` |
| 🌐 **Translate** | Open an Issue first to coordinate — we don't want duplicate effort |

## What we accept

✅ **High-signal additions:**
- Official courses from Microsoft, AWS, GCP, NVIDIA, SAP, top universities
- Industry-recognized certifications
- Frameworks/tools with > 5k GitHub stars and active maintenance
- Free + paid resources both welcome

❌ **What gets rejected:**
- Affiliate links or paid promotions (no exceptions)
- Niche tools without traction
- Listicle-style "Top 100 X" pages (we keep this curated)
- Self-promotion of personal blog posts (unless they're widely cited)

## PR checklist

Before opening a PR:
- [ ] Link works and isn't behind a paywall labeled "Free"
- [ ] Cost / duration is accurate as of your PR date
- [ ] You added it to the right level (L100–L400)
- [ ] You used the existing table format
- [ ] You ran a Markdown linter (or eyeballed the formatting)
- [ ] No more than 1–2 additions per PR (easier to review)

## Code of conduct

Be kind. Be specific. Be helpful. We're all here to learn.
