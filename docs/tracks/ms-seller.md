# 🎯 Track B — Microsoft Technical Seller / Solutions Architect

> Goal: be the **trusted AI advisor** for Microsoft customers. AI-900 → AI-102 → AZ-305 + Foundry depth + customer-ready demos.

## Profile

You work in MCAPS, partner SE, or as a technical seller / SA. Your customers ask: "Should we build with Foundry or Copilot Studio? What's the EU AI Act risk? How does this integrate with our M365 + SAP estate?"

## 4–6 month plan

### Month 1 · Foundation + AI-900
- ✅ Complete **AI-900 / AI-901 learning path** on Microsoft Learn (free)
- ✅ Read the **Microsoft Responsible AI Standard** (free)
- ✅ Watch the latest **Microsoft Build AI keynotes** + **Ignite AI sessions**
- 🎯 **Cert: AI-901** (preferred) or **AI-900** (before June 30, 2026)
- 📚 Side reading: **Microsoft AI Tour** session recordings, **Microsoft Mechanics** YouTube

### Month 2 · L200 Azure AI development
- ✅ Complete **Develop Generative AI Apps in Azure** (8 modules)
- ✅ Complete **Build AI Apps with Azure AI Services** (10 modules)
- ✅ Hands-on: deploy a **chat-with-your-data** sample using Azure AI Foundry
- 🛠️ **Demo asset #1:** Build a 10-minute Foundry walk-through with screen recording

### Month 3 · L300 Agents & AI-102 / AI-103
- ✅ Complete the **AI-102 study guide** end-to-end
- ✅ Take **Microsoft Agent Framework Quickstart**
- ✅ Build a **Copilot Studio** agent (low-code) and a **Foundry Agent Service** agent (pro-code)
- 🎯 **Cert: AI-103** (preferred) or **AI-102** (before June 30, 2026)
- 🛠️ **Demo asset #2:** Side-by-side Foundry-vs-Copilot Studio decision deck

### Month 4 · L400 Architecture + AZ-305
- ✅ Complete **AZ-305 Solutions Architect** path
- ✅ Study Microsoft's **Azure Cloud Adoption Framework for AI** + **Well-Architected Framework AI workload guidance**
- ✅ Read the **EU AI Act primer** + **NIST AI RMF**
- 🎯 **Cert: AZ-305**
- 🛠️ **Demo asset #3:** End-to-end customer reference architecture (Foundry + Purview + Defender + Entra)

### Month 5–6 · Specialization
Pick a vertical:
- **Financial Services:** AI for fraud, KYC, contact center
- **Healthcare:** Compliant AI on Azure (HIPAA, HITRUST), DAX Copilot
- **Manufacturing:** Industrial Copilot, Computer Vision
- **Public Sector:** Azure Government AI, FedRAMP
- **SAP shops:** See the [SAP + Azure track](./sap-azure.md)
