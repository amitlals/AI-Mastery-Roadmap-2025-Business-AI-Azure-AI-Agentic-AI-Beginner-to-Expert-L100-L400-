# 🎓 Track A — Student / Career Switcher

> Goal: become **employable** in AI within 6–9 months without a CS degree. Free-first, project-heavy, certification-validated.

## Profile

You're new to AI (or new to tech). You want a portfolio + cert combo strong enough to land an entry-level AI/ML role or pivot into one from an adjacent function (data analyst, BI, support, ops, junior dev).

## 6–9 month plan

### Month 1–2 · L100 Fundamentals
- ✅ Complete **Andrew Ng's "AI For Everyone"** (Coursera, free audit)
- ✅ Complete **Microsoft Learn AI-900 learning path** (free)
- ✅ Take **Elements of AI** (University of Helsinki, free)
- 🎯 **Cert: AI-900** (~$99) or **AWS AIF-C01** (~$100)
- 🛠️ Mini-project: a "Hello AI" notebook — call OpenAI/Anthropic API, summarize a Wikipedia article

### Month 3–4 · L200 Implementation
- ✅ Complete **DeepLearning.AI ChatGPT Prompt Engineering** + **LangChain for LLM App Dev** (free)
- ✅ Work through **Microsoft Generative AI for Beginners** GitHub course (21 lessons, free)
- ✅ Pick a cloud and complete one path — Azure AI Foundry **or** AWS Bedrock workshops **or** GCP Vertex AI
- 🛠️ **Portfolio Project #1:** RAG chatbot over a public dataset (e.g. arXiv abstracts, recipe DB, song lyrics). Deploy it on Hugging Face Spaces or Streamlit Cloud. Public URL + README + GitHub repo.

### Month 5–6 · L300 Agents
- ✅ Complete **AI Agents in LangGraph** + **Multi-AI-Agent Systems with crewAI** (DeepLearning.AI, free)
- ✅ Work through **Microsoft AI Agents for Beginners** + **MCP for Beginners** (GitHub, free)
- 🎯 **Cert: AI-102 / AI-103** (Azure AI Engineer) or **AWS MLA-C01**
- 🛠️ **Portfolio Project #2:** Multi-agent assistant with at least 2 MCP tools (e.g. web search + filesystem). Public demo + write-up.

### Month 7–9 · Job-ready
- 🛠️ **Portfolio Project #3:** A vertical-specific agent (e.g. legal contract reviewer, medical-record summarizer, finance reconciliation helper). Pick a domain you understand.
- ✍️ Write 3 blog posts on your projects (Medium, Hashnode, dev.to). Cross-post to LinkedIn.
- 💼 Apply: target "AI Engineer", "ML Engineer (entry)", "Generative AI Developer", "Solutions Engineer (AI)" roles.

## Cost-conscious version

Spend < $300 total:
- Free Coursera audits + DeepLearning.AI short courses
- One certification: **AI-900** ($99) or **AIF-C01** ($100)
- Free tier of Azure / AWS / GCP for projects
- Free Hugging Face Spaces hosting
- Local inference with **Ollama** instead of paid APIs

## Killer combo for the resume

| Asset | Why it works |
|---|---|
| 1 cloud cert (AI-900 / AI-901 or AIF-C01) | Filters past HR ATS keyword scans |
| 3 GitHub projects with READMEs | Gives interviewers concrete things to ask about |
| 1 deployed public demo | Shows you can ship, not just prototype |
| LinkedIn write-ups | Demonstrates communication ability |
| 1 OSS contribution (PR to LangChain, LlamaIndex, or this repo) | Signals collaboration |

## Common mistakes

- 🚫 Stacking certs without projects — recruiters glance at certs, then dig into projects
- 🚫 Building 10 toy notebooks instead of 3 polished ones — depth > breadth
- 🚫 Skipping deployment — "works on my laptop" doesn't count
- 🚫 Ignoring fundamentals — when something breaks, you need to know why
